# 404 页面

路由 `/:pathMatch(.*)*`（catch-all），没有自己的固定地址。

## 这个页面是干什么的

地址写错、或者指向已经下线的旧页面时显示。以前这一行是 `redirect: '/'`，
症状是「链接明明能用，内容却变成了首页」——用户看不出是地址错了，下次还会用同一个错链接。
现在明确说明这一页不在，并给出三个真正值得去的地方（首页 / 文章 / 相册）。

## 状态从哪来

| 界面元素 | 来源 |
| --- | --- |
| 你打开的地址 | `useRoute().fullPath`，原样显示，方便看出是不是拼错了 |
| 三个跳转按钮 | `app/usePageNav.js` 的 `go()` |

## 文件

| 文件 | 内容 |
| --- | --- |
| `NotFoundPage.vue` | 页面本体，没有状态、没有副作用 |

## 需要注意的地方

- **它没有导航入口。** 全站唯一一个「有路由、无菜单」的页面，所以 `app/navigation.js`
  里没有它；`npm run new:page` 会给新页面加菜单项，这个页面是手工注册的。
- **catch-all 必须排在 `app/routes.js` 的最后一行。** vue-router 按顺序匹配，放到前面
  会把后面所有页面都吃掉。
- `ssr-smoke` 的路径是从路由表推导的，而它会过滤掉带 `:` 的路径，所以这个页面不进冒烟测试。
  改版之后请手动打开一个不存在的地址（例如 `#/nope`）看一眼。
