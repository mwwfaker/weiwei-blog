# 时光归档

路由 `/archives`。把文章和日记混在一条「年-月」时间线上。

## 日期归一化

两边的日期格式不一样，页面里各给一个取月份的函数：

- 文章：`2026.09.18` → `2026.09`（`slice(0, 7)`）
- 日记：`2026-09-30` → `2026.09`（`slice(0, 7).replace('-', '.')`）

月份集合用 `Set` 去重后倒序排（新的在上）。

## 点击行为

| 条目 | 动作 |
| --- | --- |
| 文章 | `articles.open(article)` —— 打开阅读弹窗（由外壳挂载） |
| 日记 | `diaries.selectedDiary = entry` —— 打开日记阅读弹窗 |

## 性能

`articlesOf(month)` / `diariesOf(month)` 在模板里被每个月份调用一次，是 O(月份数 × 条目数)。
条目数量级是几百，够用；如果以后上千条，再改成先分组一次。

## 「N 件记录」只有我自己能看到的东西吗

不是。它统计的是当前已加载的**公开内容 + 自己账号里的内容**，
也就是这一页实际列出来的条目数——和列表一致，不会有对不上的数字。
