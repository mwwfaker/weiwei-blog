# 唯唯公司搜寻

路由 `/company`。输入公司名 → 打开查询页 → 三个字段粘进来 → 一键复制。

## 为什么是「打开页面 + 粘贴」

企业工商信息（类型 / 经营范围 / 地址）只在企查查、天眼查、爱企查、国家企业信用信息公示系统
这些地方有。前几家都要付费 key；国家公示系统有验证码。站主要求**零成本**、每天上千条，
所以工具不去绕过这些限制，而是把「打开哪个平台、粘哪里、复制什么」做到最省事：

- 每次按「查询」自动轮到下一家平台（分摊单站限流），也可以手动点选；
- 三个字段各一个框，点「复制」就进剪贴板；
- 「清空，查下一个」一键复位。

## 别做的事

- **不要在页面里直接爬这些站点**：CORS 挡住且违反对方条款。
- **不要把某个平台的 key 写进前端**：这是公开仓库。
- 真要做到「输入即出三行」，只有两条路：买按次计费的企业数据 API，
  或公司内部已有查询服务。两者都要先有数据源，再改 `search()` 那一处。
