# 创作管理

路由 `/admin`。内容概览 + 可见范围设置 + 快捷入口。

## 文件

| 文件 | 内容 |
| --- | --- |
| `AdminPage.vue` | 编排：标题区（含登录状态文案）与两个面板的摆放 |
| `components/AdminStats.vue` | 四个数字：文章 / 日记 / 相册 / 音乐 |
| `components/AdminSettingsPanel.vue` | 新日记默认可见范围 + 博客首页开关 |
| `components/AdminQuickActions.vue` | 五个快捷入口 + 上传错误提示 |

## 未登录时是什么样

整页只能看：标题区右侧唯一的按钮是「登录后开始记录 ↗」，
快捷入口里的动作会被各自的 `requireLogin()` 挡下并带去账号页。

## 两个设置项的性质不同

| 设置 | 存在哪 | 影响 |
| --- | --- | --- |
| 新日记默认可见范围 | `localStorage` | 只影响之后新建日记的表单初值 |
| 博客首页可见范围 | `localStorage` | 目前只影响首页/日记页上那枚提示标签的文案 |

这两项**都还没有后端配合**，不要把它们写成「已保存到账号」。

## 「退出账号」

走 `library.logout()`：先清会话，**再重读一遍全站内容**。
少了后半步，退出后自己账号里的私密内容会继续留在屏幕上。

按钮点完会 `go('account')`，所以 `await` 之后再跳转。
