# 工具箱

路由 `/tools`。

## 这个页面是干什么的

工具类页面的**统一入口**：一张卡片一个工具，点了跳到对应页面。
它自己不做任何业务，只维护 `tools` 清单。

## 状态从哪来

| 界面元素 | 来源 |
| --- | --- |
| 工具卡片 | 本文件里的 `tools` 数组（`id` 必须同时是路由名） |
| 跳转 | `app/usePageNav.js` 的 `go()` |

## 文件

| 文件 | 内容 |
| --- | --- |
| `ToolsPage.vue` | 页面本体：只有工具清单和链接 |
| 样式 | 在 `styles/shell-2026.css` 的「工具箱」一节 |

## 需要注意的地方

- **不要放「规划中」的占位卡。** 之前有三张（图片批处理 / 文本对比 / 二维码生成），
  只是为了页面显得不空，结果既点不动也永远做不完。工具页只列真正能打开的东西；
  加新工具 = 先建页面、再加进 `tools` 数组。
- 工具页是内页，顶栏和粒子背景都在；绩效计算器与快捷复制从工具卡片进入，并使用整屏工具布局。
- `tools` 里每一项的 `id` 会被第 [3] 项拿去核对路由和页面注册表，写错会在 `verify` 里报出来。
