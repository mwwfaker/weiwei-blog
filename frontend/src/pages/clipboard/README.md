# 快捷复制

路由 `/clipboard`，入口在工具箱。整屏工具页（和绩效计算器一样隐藏博客顶栏，自带顶栏与返回）。

## 这个页面是干什么的

把工作中反复要粘贴的内容存成数据卡片：**点一下那一条就复制**，去别的软件直接粘贴。

- **分类工作表**（顶部的「常用 / 工作 / 生活」）：不同场景分开存，像 Excel 的 sheet，切换不串数据。
- **数据组**：一条数据是一张卡片；多条一起粘贴进来会自动成为一组，卡片里用竖线连起来，点卡片右上角可以整组复制。
- 拖动可排序；卡片拖到分类标签上就换组。
- 数据只存在**这台浏览器的 localStorage**（键 `weiwei.clipboard.workspace.v1`），不登录、不上传。

## 状态从哪来

| 界面元素 | 来源 |
| --- | --- |
| 分类、卡片、顺序 | `services/clipboardStorage.js` 读写的 workspace；单页工具，状态不进 store |
| 搜索词、弹窗开关、拖动/复制高亮 | 本页 `ref` |
| 提示 | 页内的 `notice`（不走上层 toast：工具页没有博客外壳） |

## 文件

| 文件 | 内容 |
| --- | --- |
| `ClipboardPage.vue` | 页面本体：顶栏、分类标签条、卡片网格、拖动、两个弹窗、复制 |
| `clipboard.css` | 本页样式，由页面 `import`，跟着异步 chunk 走 |
| `services/clipboardStorage.js` | 读写本机数据 + 生成 id（不 import Vue，可离线对拍） |

## 需要注意的地方

- **复制要留退路。** 局域网 http 地址下 `navigator.clipboard` 不存在，所以 `copyValue`
  里有 textarea + `execCommand` 的兜底；只写前者会出现「点了有反应、粘出来是空的」。
- **写 localStorage 可能超额**（粘贴了很长的文本）。`writeClipboardWorkspace` 会抛错，
  页面接住并提示「数据暂未保存」，不要让它冒到控制台把整页打断。
- **卡片顶部的字只是「插图」，不是标题。** 它取首条数据的首字符（链接/邮箱/电话会给对应图标），
  所以卡片上不会出现「标题 + 一样的内容」两遍——上一版就是这么重复的。
- 分类至少保留一个；删除分类会连同里面的卡片一起删，所以走 `window.confirm`。
- `isToolPage` 里登记了 `clipboard`：工具页靠它隐藏博客顶栏和粒子层，样式在
  `styles/effects-and-fixes.css` 的 `.app-shell.tool-mode` 一节。加整屏工具时记得同步那里。
- 这一页**不做窄屏适配**（站主明确说不需要）：桌面是主场景，手机上能用但不专门排版。
