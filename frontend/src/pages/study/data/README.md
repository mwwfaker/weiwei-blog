# `pages/study/data/` — 学习路线的课程数据

`studyPlan.js`：29 门课 / 5 个阶段的结构化数据，由《金融学系统自学路线》原始文档生成。

## 约定

- **这是内容，不是代码。** 课程名、阶段、资源链接都属于「站主写下的东西」，
  和 `src/data/seed.js` 里那种「接口没答上来时用的示例」是两回事——所以它跟着页面走，
  而不是放进 `src/data/`。
- **不要在前端改写内容。** 要改课程就改这个文件（或重新从原始文档生成），
  不要在 `StudyPage.vue` 里做字符串处理。
- 体量约 300 kB，所以 `StudyPage.vue` 是按需加载的（见 `src/app/pageRegistry.js`）。
