# `modules/particle/` — 背景粒子

`ParticleField.vue`：整屏的 Canvas 粒子背景，按主题取色，用 Web Audio 频谱驱动律动。

## 为什么要单独一个文件夹

它是纯视觉、和博客内容毫无关系的组件，唯一的调用点在外壳，而且带着一整套自己的性能约束。
放在 `modules/` 下而不是 `components/` 里，是因为「谁在用我」这个问题的答案它自己说不清——
它就是一块画布。

## 几条不能随手改的实现约束

- **连线用格子分桶，不是两两比较。** 两层循环在几百个粒子上就是 O(n²)，会直接把主线程吃掉。
- **不能给画布加 `mix-blend-mode: screen`。** 对近白背景做 screen 还是近白，浅色主题下粒子会整片消失。
  颜色改成按主题各取一套（见 `PALETTE`）。
- **透明度不能低于 0.2。** 低于这个值画布实际上已经看不见了。
- `npm run verify` 的第 [5]、[6] 项会盯着上面两条。

## 省电模式

`低电模式`（完整动效 → 省电模式）打开时整个画布不渲染，由外壳的 `v-if="!music.lowPower"` 控制。
